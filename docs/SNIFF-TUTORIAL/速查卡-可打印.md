# 到底要抓什么包 · 一页速查卡

> 完整图文版见同目录 `index.html`（双击打开，截图已内嵌，不需要联网）。
> ⚠️ 界面截图里的 `7 帧 / 100.0%` 是程序自测的假样本，不是真机抓包结论。

---

## 一句话答案

抓 **服务器 → 客户端** 的 **7 种数据包**，目的只有一个：**数格子**（数一串字节里到底多没多那 1 个 / 8 个字节）。因为三份说明书互相打架，只能看真实服务器发的原始字节。

---

## 抓哪 7 个包

| 包（编号） | 中文 | 游戏里怎么逼它出来 |
| --- | --- | --- |
| `add_player` (12) | 有玩家进你视野 | 开两个客户端 / 朋友进服，**让 TA 空手，再拿个东西** |
| `add_actor` (13) | 生成生物 | `/summon sheep` |
| `add_item_actor` (15) | 地上出现掉落物 | 按 `Q` 扔东西 |
| `move_player` (19) | 玩家被传送 | `/tp @s ~ ~10 ~` |
| `mob_equipment` (31) | 生物换手持物 | 看拿东西的僵尸 / 给生物装备 |
| `mob_armour_equipment` (32) | 生物换盔甲 | 给生物穿盔甲 |
| `set_actor_data` (39) | 实体属性变化 | 打一下生物 / 用命名牌 |

**只抓服务器→客户端方向**，客户端发出去的不看。主抓新版服务器（1.26.40+，协议 2168/2193/2225）。

**最小验收只要 3 帧**：一个「手持为空」的 12 或 31、一个「有至少 1 条属性」的 13 或 39、一个「传送」的 19。建议抓 20～50 帧，投票更稳。`mob_equipment` 包最短，错一格立刻暴露，是判空手最便宜的一帧。

---

## 三个悬案（到底在数什么）

| 悬案 | 两种说法 | 界面上怎么看 | 结论怎么落到代码 |
| --- | --- | --- | --- |
| **A 空手占几格** | 老版 1001 读到 0 就结束（1 字节）；新版 2168 固定 2 字节编号且**空栈也写满 8 字节** | `empty 8B` = 写满；`empty 1B/2B` = 短路。结论行 `air-layout air-full / air-short` | `air-full`：`item1001To2168` 的 air 分支保持补写尾部；`air-short`：改成只写 2 字节 |
| **B 属性有没有多 1 字节** | 每条属性是 `[编号][类型][值]`，还是 `[编号][类型][legacy_type][值]`（且该字节必须等于类型） | `sel 4/4` = 4 条全都有；结论行 `metadata-legacy-type present / absent`；`metadata-sanity ... 20/20` 是校验 | `present`：翻译 12/13/15 时每条插 1 字节；`absent`：**什么都别加**（很可能只是社区资料建模错了） |
| **C 传送前有没有开关** | `[模式][原因][来源]`，还是 `[模式][01/00][原因][来源]` | `tp bool=true`；结论行 `teleport-option present / absent` | `present`：翻译 19 时补 `01`；`absent`：该包不用翻译 |

顺带会判的两个（不是主目标）：`item-layout`（`item-instance` / `item-v1`，物品编号编码方式）、`passenger-of-block`（玩家/生物包末尾有没有多一段骑乘方块记录）。

---

## 工具凭什么能下结论

同一帧字节，用**所有可能的假设**各拆一遍。要求：字节不能不够读、不能多出来、数值不能荒唐。
**只有唯一一种假设刚好把字节一个不剩读完 → 它才有投票权**；两种都行 = `ambiguous`（不投票）；都不行 = `no match`（红，不投票）。汇总所有有票的帧出比例，100% 一致才算结论。

## 操作步骤

### 准备

```bash
git clone https://github.com/fengyushaonian/bedrocktool.git
cd bedrocktool
git checkout feat/packet-sniffer
git submodule update --init --depth 1     # 子模块必须拉
go build -tags gui -o bedrocktool ./cmd/bedrocktool   # 漏 -tags gui 就没界面
./bedrocktool        # 不带参数 = 图形界面；带参数 = 命令行
```

Linux 编译前先装：`sudo apt install -y gcc libgl1-mesa-dev libx11-dev libx11-xcb-dev libxkbcommon-x11-dev libxfixes-dev libxcursor-dev libxrandr-dev libxinerama-dev libxi-dev libvulkan-dev libwayland-dev`

### 离线路线（推荐先做，不用账号）

1. 先弄到 `.pcap2`：GUI 跑 `worlds` 模式（`capture` 默认勾选）进一次服，或 `./bedrocktool capture -address 服务器:19132` → 落在 `captures/`。**录像里必须真的做过第 2 节那些动作**。
2. GUI 设置页点 **`sniff`** 按钮（第 3 个）。
3. `Pcap File` → `select file` 选 `.pcap2`；**`Address` 留空**；`Output` 填**绝对路径**；`Max Packets` 填 `0`。
4. 点 **`Start`** → 自动切到 Sniffer 页，逐帧刷新。
5. 点 **`Stop`** → 看底部 `VERDICT` → 点 **`Save report`**。

### 实时路线（抓真包）

1. `Address` 填真服务器 `play.example.com:19132`；`Pcap File` 留空。
2. `Listen Address` 默认 `0.0.0.0:19132`；被 BDS 占用就改 `0.0.0.0:19133`（客户端也连 19133）。
3. 点 `Start`，**记下界面中间那句 `Connect your client to ...` 显示的地址**（端口以实际显示为准，不是固定 19132）。
4. 客户端 → 多人游戏 → 添加服务器 → 填那个地址；首次弹微软账号登录，登完代理才转发。
5. 进世界，把动作全做一遍：第二人进服（空手 + 拿东西）→ `/summon sheep` → 按 Q 扔东西 → `/tp` → 打一下生物。
6. 攒 20～50 帧 → `Stop` → `Save report`。

### 命令行（不开界面）

```bash
./bedrocktool sniff -pcap captures/server.pcap2 -out sniff.jsonl -max 0          # 离线
./bedrocktool sniff -address play.example.com:19132 -listen 0.0.0.0:19133 -out sniff.jsonl   # 实时
./bedrocktool sniff -pcap captures/server.pcap2 -out sniff.jsonl -verbose       # 排查
```

## 读结果

顶部四个数字：`packets` 总数、`matched` 唯一命中（**有投票权**）、`ambiguous` 歧义（不投票）、`unmatched` 无匹配（不投票）。
颜色：正常 = 唯一命中，**琥珀 = 歧义**，**红 = 无匹配**。

底部要看的三行（**都要 100.0%**）：

```
air-layout             air-full / air-short         → 悬案 A
metadata-legacy-type   present / absent             → 悬案 B
teleport-option        present / absent             → 悬案 C
```

另外确认 `metadata-sanity ... N/N`、`teleport-option` 至少 1 帧（必须真 `/tp` 过）、`unmatched=0`。

不到 100%（如 `air-full 12/14`）= 录像混了版本，或解析器还有没覆盖的字段 → 勾 `verbose` 重跑，看那几帧卡在第几字节，或重录一份只连一个版本。

输出文件：`sniff.jsonl`（每帧 JSON + hex + 全部候选）、`sniff.jsonl.summary.txt`、`<pcap>.verdict.txt`、`sniff-report-<时间>.txt`。

## 常见坑

| 现象 | 处理 |
| --- | --- |
| 弹 `no address given` | Address 和 Pcap File 至少填一个 |
| 没有 `sniff` 按钮 | 编译漏了 `-tags gui` |
| 一直 `Waiting for packets` | 客户端没连界面提示的地址端口，或还没进世界 |
| 端口起不来 | 19132 被占，改 19133，客户端同步改 |
| 全红 `no match` | 版本不对 / 有未覆盖字段，勾 `verbose` |
| 到 2000 帧就停 | `Max Packets` 填 `0` |
| 只有 `add_player` 没传送 | 没真 `/tp`，动作清单要做全 |
| 找不到报告 | `Output` 用了相对路径，落在启动目录 |
